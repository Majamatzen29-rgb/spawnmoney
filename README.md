# spawnmoney

## Installation

1. Download the **spawnmoney ZIP**.

2. Open the ZIP.

3. Inside the ZIP, you will see **spawnmoney-main**.

4. Open **spawnmoney-main**.

5. Inside **spawnmoney-main**, you will see **spawnmoney**.

6. Open **spawnmoney**.

7. Inside **spawnmoney**, you will find:

   * `fxmanifest.lua`
   * `server.lua`

8. Take the **spawnmoney** folder.

9. Put the **spawnmoney** folder into your FiveM server's **resources** folder.

10. Open `server.cfg`.

11. Add:

```text
ensure spawnmoney
```

12. Restart your server.

## Usage

Use:

```text
/spawnmoney [amount]
```

Example:

```text
/spawnmoney 5000
```

You can enter any amount you want.

## Requirements

* Qbox
* FiveM

## Permissions

No ACE permission is included by default.

Server owners can add their own ACE permission if they want to restrict the command.
